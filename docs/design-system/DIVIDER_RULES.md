# Dividers, Rules and Borders

**Date:** 2026-08-14 (Phase 5A)

**Established constraint (Phase 4, #25):** rules, boxes and colour may not be the primary separator between reasoning and apparatus. That separation is typographic. This document defines where rules *are* permitted.

---

## Policy

### ALLOWED — rules that report real structure

| Use | Justification |
|---|---|
| **Above the footer** | Marks the end of content; a genuine boundary |
| **Between index items** *(optional)* | Only if rhythm alone proves insufficient at density. Prefer space |
| **Beneath the site identity in the header** *(optional)* | Only if the header would otherwise float ambiguously into content |
| **Table rules** | Where a real table exists, rules aid row tracking |
| **Around figures** | A figure boundary carries information |

### LIMITED — permitted with a stated reason

| Use | Condition |
|---|---|
| Above an artifact group | Only if 5D shows artifacts are hard to locate. **One hairline, never a panel** |
| Blockquote marker | A single left rule is acceptable; a bordered box is not |
| Between major page sections | Only where space alone fails at that density |

### AVOID

| Use | Why |
|---|---|
| Between title and masthead | They belong together — space handles it |
| Between masthead and prose | **This is the register boundary.** A rule here would violate constraint 25 outright |
| Around the masthead | Makes it a card |
| Around inline insets | Makes them callouts |
| Around the uncertainty statement | VP-4 |
| Between investigation movements | Space is the marker (VP-5). Rules would fragment the argument into sections |
| As decoration | Any rule not carrying structure |
| Multiple weights as a system | One hairline weight is sufficient |
| Vertical rules | With one column there is nothing to separate |

---

## Rule specification

**One weight. One colour. Very low contrast.**

A rule should read as a *change of state*, not as a graphic element. If it is the first thing noticed on the page, it is too strong.

**No dotted, dashed, doubled, or gradient rules.** No decorative flourishes, no ornamental dividers.

---

## Can the site remain coherent with almost no rules?

**Yes — and it should.** The structural work is already done by three other mechanisms:

1. **Vertical rhythm** separates movements (VP-5).
2. **Type register** separates prose from apparatus (`TYPE_CONTRAST.md`).
3. **The shared left edge** binds everything into one column.

Rules would be a fourth mechanism doing work already done. **Redundant structure is decoration.**

**Realistic total: one rule above the footer, possibly one beneath the header.** Everything else is space and type.

---

## Why the temptation will recur

At 5D and 5E, pages will look sparse. The instinct will be to add rules to make the structure "clearer."

**That instinct is usually wrong here**, and there is a specific diagnostic:

> If a rule seems necessary, the spacing scale is probably too flat — inter-movement space is not sufficiently larger than inter-paragraph space.

**Fix the rhythm, not the borders.** A rule added to compensate for weak spacing hides the problem and adds a permanent element.

**The one legitimate exception:** if user testing shows readers genuinely cannot locate the uncertainty movement, VP-4's stated remedy is *a heading* — not a rule, tint, or box.

---

## Test

> **Remove every rule from the page. Is anything now ambiguous?**

Whatever becomes ambiguous earns a rule. Everything else does not.

# Visual North Star

**Date:** 2026-08-14 (Phase 5A) · Translating *"working papers — kept well enough that a stranger can follow the thinking"* into visual behaviour.

---

## What the visitor SEES

**A page that is mostly text, set with obvious care.**

- A single column of reading, at a width that signals *this is meant to be read* rather than scanned.
- A compact block of factual context at the head of each investigation — date, status, domain, origin — set in a different type register, tighter and smaller.
- Occasional short asides in that same secondary register, sitting inside the flow of reading rather than beside it.
- Almost no rules, no boxes, no cards, no icons, no images.
- One accent, rarely.

**Nothing that looks like an interface.** No panels, no chrome, no controls except navigation and (at volume) filters.

---

## What the visitor FEELS

| Feeling | Produced by |
|---|---|
| **Someone kept this carefully** | Consistent rhythm; nothing misaligned; metadata always in the same place |
| **This is unhurried** | Generous vertical space around prose; no motion; no urgency devices |
| **This person is precise** | Small, exact metadata; specific language; no rounding, no superlatives |
| **This is honest** | Uncertainty set in the same type as everything else, in the same place every time |
| **I can trust the structure** | The second investigation reads exactly like the first — position is learnable |

**The intended overall feeling is *composure*.** Not impressiveness, not warmth, not authority. The visual equivalent of someone explaining their work calmly and completely.

---

## What the visitor should NOTICE

1. **That the reasoning is the main thing on the page.** It occupies the most space, the largest type, the primary column.
2. **That there is a second, quieter register** carrying facts about the work rather than the work itself — and that it is consistently subordinate.
3. **That the piece states what could not be determined**, in the same voice and weight as everything else.
4. **That dates are everywhere** — nothing pretends to be timeless.
5. **That it is small, and looks deliberate rather than unfinished.**

---

## What the visitor should NOT NOTICE

| Should not notice | Why |
|---|---|
| The grid | It should feel inevitable, not designed |
| The type sizes | Hierarchy should be felt, not measured |
| The colour | An accent at ~2% should register as emphasis, not as branding |
| Any transition | Motion is near-zero; anything perceptible has failed |
| The absence of images | It should read as *nothing was needed*, never as *something is missing* |
| The absence of an artifact | Renders as nothing; no gap, no placeholder |
| The design at all, on first read | The content should arrive before the container does |

**The last one is the real target.** A visitor should finish an investigation thinking about Het's reasoning, and only afterwards notice the page was well made.

---

## Operational definitions

Terms banned unless defined. These are the definitions.

| Term | Means, here |
|---|---|
| **Spare** | Fewer elements, each carrying more. Measurable: no element exists without a stated function |
| **Precise** | Metadata exact to the level it is known; no rounding; no unverifiable numbers |
| **Composed** | Consistent rhythm and position across pages; nothing that jumps |
| **Deliberate** | Every irregularity traceable to a reason in this documentation |
| **Quiet** | Emphasis is rare — accent ~2% of elements, motion near-zero, no more than one emphatic element per screen |
| **Considered** | The typographic detail rewards close attention but does not demand it |

---

## The failure states, named

| Failure | Looks like | Guard |
|---|---|---|
| **Unfinished** | Sparse and careless — inconsistent spacing, default type | Craft. With no imagery or motion, typography carries everything |
| **Editorial magazine** | Large display type, pull quotes, image-led | No pull quotes; display type restrained; near-zero imagery |
| **Design portfolio** | Warm neutral + serif + generous space, and nothing technical | Mono for literal values; dense factual apparatus; precise language |
| **Academic paper** | Formal, third-person, reference-heavy | First-person voice; no abstract, no citations apparatus |
| **Corporate** | Even, safe, impersonal | First-person reasoning; visible uncertainty; no badges |

**The two closest failure states are *design portfolio* and *unfinished*** — the warm-neutral-plus-serif direction sits near the first, and the near-zero-motion-and-imagery decision sits near the second. Both are managed by the same thing: the density and specificity of the apparatus. It is what makes the page read as a working record rather than a styled surface.

---

## The single test

> **Does the page look like something that was kept, or something that was made?**

*Kept* is the target. Made is what a portfolio looks like.

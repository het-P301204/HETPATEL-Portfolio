# Visual Metaphor

**Date:** 2026-08-14 (Phase 4)

---

## Does the site need one?

Phase 1 established the failure mode precisely, with a measured example: **a metaphor applied only to vocabulary is costume.** zyekh.cloud labels its sections `SYSTEM_OVERVIEW`, `CORE_REPOSITORIES`, `TECHNICAL_DOMAIN` and presents terminal chrome with no terminal function. The metaphor reaches the labels and stops.

**The disqualifying test, carried from Phase 1:** *if you delete the metaphor's vocabulary, does the architecture still stand?*

| **Investigation** | Already the content unit — structural, not decorative | Could invite detective-board imagery | Low, if it stays linguistic | Excellent | Low | **Very high** |
| **Notebook** | Personal, honest about incompleteness | Skeuomorphic pull: paper, torn edges, handwriting | **High** | Good | Low | High |
| **Archive** | Order, permanence, retrievability | Institutional coldness; the Register's corporate failure | Moderate | Excellent | Low | Moderate |

| **None** | Zero gimmick risk | Nothing to bind the design | None | Excellent | Moderate | Moderate |

---

## Recommendation: the metaphor is **linguistic and structural, not visual**

**The metaphor is INVESTIGATION.** It already exists — as the content unit, as the navigation label, as the shape of every page. It requires **no visual expression whatsoever.**

This is the important conclusion. The site does not need a visual metaphor *layered on top of* an investigation-centric architecture, because the architecture already is one. Adding imagery would be the zyekh failure in reverse — decoration applied to a structure that is already coherent without it.

**It passes the disqualifying test conclusively.** Delete the word "investigation" and the architecture stands: a question, reasoning, findings, an admitted limit, dated and statused. The metaphor is load-bearing at the structural level and absent at the decorative one.

---

## What this rules out

| Ruled out | Because |
|---|---|
| Detective imagery — pins, string, corkboard | Literal simulation; the exact failure named in the brief |
| Magnifying glasses, footprints, evidence tags | Iconographic literalism |
| Paper textures, torn edges, handwriting | Skeuomorphism; the notebook trap |
| File folders, stamps, classification markings | Also the confidentiality-as-gimmick failure |
| Network nodes, constellations, graphs as decoration | Banned; systems metaphor's failure mode |
| Waveforms, signal traces, glow | Signal metaphor's failure mode |
| Maps, terrain, cartographic ornament | Requires coverage that does not exist |

---

## What the metaphor *does* express

Through structure and language only:

1. **An investigation may be unresolved** — `unresolved` is a real status. Portfolios do not usually permit failure; investigations do.
2. **An investigation has a question, not a title claim.** Headings phrased as questions rather than achievements.
3. **An investigation accrues over time** — the apparatus records revisions with dates. Investigations get revisited; projects get finished.
4. **What could not be determined is part of the record.** An investigation that omits its gaps is a bad investigation. This is why the honesty requirement feels native rather than imposed.

**Every one of these is language or structure. None is a graphic.**

---

## The one permitted visual expression

**The apparatus itself** — the secondary register carrying dates, status, uncertainty and revision.

It is not a picture of an investigation; it is the working record *of* one. It earns its place because it holds real information, and it would be visibly empty on a site without candid content — which is precisely why it is the one element that cannot be lifted onto another student's portfolio.

**If the apparatus ever becomes decorative — a styled gutter with nothing in it — the metaphor has become costume and it should be removed.**

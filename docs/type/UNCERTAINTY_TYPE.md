# Uncertainty Typography

**Date:** 2026-08-14 (Phase 5C)

---

## The specification

**None.**

The uncertainty statement is set in **Newsreader Text, 19px, weight 400, line-height 1.65, primary text colour** — byte-for-byte identical to the paragraphs around it.

| Property | Value |
|---|---|
| Family | Newsreader Text — same as body |
| Size | 19px — same as body |
| Weight | 400 — same as body |
| Colour | Primary text — same as body |
| Italic | **No** |
| Indentation | **No** |
| Quotation marks | **No** |
| Container | **No** |
| Icon | **No** |
| Heading | **No** (by default) |
| Space above | **OPEN — same as every other movement** |

---

## Tested alternatives, all rejected

| Option | Why proposed | Why rejected |
|---|---|---|
| Italic | Marks it as a different kind of statement | Italic is reserved for genuine emphasis; at paragraph length it harms readability; and it reads as an aside — which this is not |
| Slight weight increase | Prevents skimming past | Contradicts the weight discipline; also reads as *importance*, when the point is that this is ordinary rigour |
| Indentation | Sets it apart structurally | Creates a second left edge, breaking the single-alignment rule that holds the page together |
| Blockquote treatment | Visually distinct, no colour | Implies quoted material |
| Extra space above | Draws the eye | Emphasis by another route; also breaks the movement rhythm |
| Smaller / muted | Marks it as a caveat | **Inverts the site's premise.** It is not a caveat |
| A "Limitations" heading | Findable | Converts a movement of the argument into a form field |

**The pattern, again:** every intervention that makes uncertainty *more visible* makes it *less credible*, because it converts a candid statement into a designed feature. The credibility comes precisely from its being written and set like everything else.

---

## How a reader finds it

**Position.** It is always the final prose movement, always before artifacts, in every investigation. A first-time reader meets it in sequence; a returning reader knows where it is.

**Consistency is the mechanism, and it costs nothing.**

---

## The escape hatch, unchanged

If 5D shows readers **demonstrably** miss it — not "might", but do — the single permitted remedy is a **heading at L2 in Newsreader**, phrased in Het's own words rather than as a label.

Not a box. Not a tint. Not an icon. Not italic. **A heading is a structural device consistent with the rest of the document; everything else is a component.**

This requires evidence from a rendered prototype.

---

## Interaction with the `unresolved` status

Independent. An investigation may state what it could not determine and still be `closed` — a conclusion was reached with a boundary acknowledged. That is the common case.

`unresolved` is reserved for investigations where no satisfactory conclusion was reached at all. **Both carry the uncertainty movement.**

---

## The test

> **Could a reader tell, from the typography alone, that this paragraph was the site's most distinctive feature?**

**They must not be able to.** If the type announces it, the type has broken it.

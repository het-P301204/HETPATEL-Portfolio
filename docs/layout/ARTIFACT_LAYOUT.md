# Artifact Layout

**Date:** 2026-08-14 (Phase 5B)

**Established rule:** reasoning first, artifact second.

---

## Placement

After the final prose movement, separated by **MAJOR** space. Before the foot register.

```
what I couldn't determine
      ── MAJOR ──
artifacts
      ── MAJOR ──
foot register
```

**No heading by default.** The register change — sans, tighter, list-shaped — plus MAJOR space is sufficient. If 5D shows artifacts are genuinely hard to locate in a 2,000-word investigation, the permitted remedy is a small label, **not** a container or rule.

---

## Form

A short list, one artifact per line, at the reading measure, left edge shared.

Each entry: **descriptive link text**, optionally followed by a brief qualifier.

```
Rule comparison tool — repository          works for the two providers tested
Trust boundary diagram                     the version discussed above
```

- Link text describes the thing, never "GitHub" or "Link".
- Repository names, where shown, are literal values (mono, 5C).
- **Qualifiers state honest state** — "partial", "no longer maintained" — in prose, not as badges.

---

## When there is no artifact

**Nothing renders.** No heading, no empty list, no "artifact unavailable", no reserved space.

The prose simply ends, then the foot register or related work follows. **A reader has no way to tell that an artifact was absent rather than never expected** — which is required by the confidentiality principle (omission is silent) and by VP-7.

**This is the common case.** Most professional investigations will have no publishable artifact.

---

## Keeping artifacts as evidence, not attraction

| Mechanism | Effect |
|---|---|
| Position after reasoning | The reader has already understood *why* before seeing *what* |
| Text, not thumbnails | No visual pull competing with prose |
| No container | Not a discrete object to be scanned to |
| Subordinate register | Visually quieter than the argument |
| No counts | Volume never surfaced |
| Descriptive link text | The link describes the evidence, not the platform |

**The index reinforces this:** artifact presence is at most a quiet indicator, never a screenshot. A visitor cannot browse the site by artifact at launch, and the artifact index only appears past ~15 artifacts as a filtered view.

---

## Screenshots and figures

If an artifact includes a screenshot or diagram, it is a **figure** — one of only two permitted containers — placed **inside the reasoning** at the point it is discussed, not in the artifact list.

The artifact list holds links. Figures illustrate arguments. They are different things and are not merged.

---

## Growth

| Artifacts | Treatment |
|---|---|
| 0 | Nothing renders |
| 1–3 | Inline list as above |
| 4+ on one investigation | Unusual; may warrant a small label |
| 15+ site-wide | An artifact index appears — **a filtered view of investigations**, never a separate section |

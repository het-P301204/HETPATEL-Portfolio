Network Vulnerability Scanning Lab

Status
closed
Origin
self-initiated

I wanted to build a home lab to practise vulnerability scanning and learn how the standard tooling works in a realistic environment.

I set up three virtual machines and configured a vulnerable target using a well-known intentionally insecure image. I then ran Nmap for service enumeration, Nikto for web server checks, and OpenVAS for a full vulnerability assessment. I documented each finding and mapped the results to their corresponding CVEs.

What I could not determine is how these results would differ in a production environment with proper network segmentation.
